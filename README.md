# Work-Up Job Portal

This repository contains both the client-side and server-side code for the Work-Up Job Portal project. This is a practice project focused primarily on functionality rather than design.

## Live Demo

You can access the live client-side application here: [https://work-up-client.web.app/](https://work-up-client.web.app/)

## Project Structure

This repository is divided into two main parts:

*   **`work-up-client/`**: The front-end application built with React.
*   **`work-up-server/`**: The back-end API built with Node.js and Express.

## Deployment

*   The client-side application is deployed on **Firebase**.
*   The server-side application is deployed on **Vercel**.

## Technologies Used

### Client-Side (`work-up-client/`)

*   **Framework:** React
*   **Build Tool:** Vite
*   **Styling:** Tailwind CSS, DaisyUI
*   **Routing:** React Router
*   **Authentication:** Firebase
*   **Data Fetching:** TanStack Query

### Server-Side (`work-up-server/`)

*   **Node.js:** JavaScript runtime environment.
*   **Express.js:** Web application framework for Node.js.
*   **MongoDB:** NoSQL database.
*   **dotenv:** Module to load environment variables from a `.env` file.
*   **cors:** Middleware to enable Cross-Origin Resource Sharing.
*   **cookie-parser:** Middleware to parse cookies.
*   **jsonwebtoken:** To generate and verify JSON Web Tokens.

## Getting Started

Please refer to the individual `README.md` files within the `work-up-client/` and `work-up-server/` directories for detailed instructions on how to set up and run each part of the project locally.
